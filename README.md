# AutoCheckin

扫码即用的自动签到桌面应用。不用复制 Cookie，也不用写配置。

## 怎么用

1. 打开 AutoCheckin，点 **＋ 添加账号**
2. 选平台，用手机 App 扫屏幕上的二维码，然后在手机上确认登录
3. 勾选要做的任务，选好每天几点执行
4. 点 **立即签到** 试一次，每项任务都会显示 ✔ 成功 / ✔ 已完成 / ✘ 失败及原因

关掉窗口后程序会继续在托盘运行，每天按时自动执行。失败的任务会每隔 30 分钟重试，每天最多 3 次。登录过期时会提示你重新扫码。

## 支持的平台

| 平台 | 任务 |
| --- | --- |
| 网易云音乐 | 手机端每日签到（领云贝）、电脑端每日签到 |
| 哔哩哔哩 | 每日观看视频、每日分享视频、每日投 1 枚硬币（默认关闭）、漫画签到 |
| 百度贴吧 | 签到所有关注的吧（逐个签到，显示新签 / 已签 / 失败及原因） |
| 洛谷 | 每日打卡（显示今日运势） |

网易云、B 站用手机 App 扫码登录；贴吧、洛谷会打开官方登录窗口，由你自己登录（验证码也是你自己完成），程序只在登录完成后读取登录 Cookie。

**只有确认过的结果才算成功**（贴吧：签完重新读取关注列表的签到状态；洛谷：打卡后重新读取首页是否显示今日运势）：每个任务执行完后都会再查一次平台的状态接口。网易云查 `mobileSign` / `pcSign`，B 站查每日任务状态和漫画签到状态。平台确认已完成才显示成功；接口说成功但平台状态没变，会显示失败。

## 安全与隐私

- **只在本机**：没有自己的服务器，没有统计 / 遥测。
- **网络白名单**：程序只会访问 `music.163.com`、`bilibili.com`、`baidu.com`、`luogu.com.cn` 及其子域名的 HTTPS 地址；其它地址（包括跳转）一律拦截。登录窗口也只允许在对应平台域名内跳转。AI 服务只有你在“高级设置”里自己填写并开启后才会访问。
- **凭据加密**：登录信息用系统钥匙串加密（Windows DPAPI / macOS 钥匙串 / Linux libsecret）。钥匙串不可用时改用本机 AES-256-GCM 密钥文件（权限 0600），设置页会明确提示这比钥匙串弱；任何情况下都不会明文保存。
- **不记录 Cookie**：日志和执行记录里不写入 Cookie；登录窗口使用独立的临时会话，登录完成后立即清除。

“高级设置”里有一个可选的 AI 功能，可以用大白话解释失败原因。开启后只发送脱敏后的结果文字，不发送登录信息。

## 开发

需要 Node.js 22、pnpm 10。

```bash
pnpm install
pnpm dev          # 开发模式
pnpm test         # 单元测试（HTTP 全部模拟）
pnpm run typecheck && pnpm run build
```

### 新增一个平台

1. 在 `src/main/core/platforms/` 下新建文件，实现 `Platform` 接口（`src/main/core/platform.ts`）：
   - `qrStart` / `qrPoll`：扫码登录。`HttpSession` 会自动收集 Set-Cookie
   - `profile`：校验登录。登录失效时抛 `LoginExpiredError`
   - `run`：执行任务。**执行完必须查询平台状态确认**，确认后才能返回 `success` / `already`
2. 在 `platforms/index.ts` 的 `PLATFORMS` 里加一行
3. 用 nock 写测试，参考 `tests/netease.test.ts`

界面会自动显示新平台和它的任务开关，不需要改界面代码。
